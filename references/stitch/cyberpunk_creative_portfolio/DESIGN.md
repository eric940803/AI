## Brand & Style

This design system targets elite entertainment concept artists, keyframe illustrators, and 2D visual developers operating within the dystopian, sci-fi, and dark fantasy industries. The brand aesthetic merges high-tech terminal interfaces, neon-lit sprawl underworlds, and premium editorial digital art presentation.

The interface evokes an immersive, high-stakes military-spec or covert netrunner HUD: hyper-focused, lethal, and visually arresting. High-fidelity illustrations remain the hero assets, encased within a structured framing of semi-translucent dark slate panes, sharp digital overlays, dynamic scanline rasters, and targeted chromatic aberrations.

The core visual style is **Cyberpunk Glass-Tech**:
- **Dystopian Atmosphere:** Deep pitch-black voids contrasted against tactical wireframe grids and subtle atmospheric scanlines.
- **Precision HUD Overlays:** Technical calibration marks, micro-coordinates, angled corner clips, and segmented visual data meters.
- **Controlled Luminescence:** Restrained neon radiance focused on active hitboxes, critical alerts, and showcase framing, ensuring neon glows complement rather than overpower the portfolio artwork.

## Colors

The palette balances pitch-black structural foundations with saturated luminescent highlights to establish high visual hierarchy and focal steering.

- **Pitch Black (`#09090F`):** Canvas backdrop and deep negative space. Prevents washed-out contrast and anchors dark artwork seamlessly.
- **Neon Cyan (`#00F5FF`):** Primary system driver. Dictates interactive targets, primary hover states, active tab indicators, and tactical HUD brackets.
- **Electric Purple (`#9D4EDD`):** Secondary structural accent. Powers ambient border gradients, nested card layers, telemetry metadata, and secondary interactive states.
- **Neon Pink (`#FF2E93`):** High-priority tertiary anchor. Reserved strictly for critical CTAs (e.g., "Commission Inquiries", "Acquire Print"), error notifications, live project tags, and glitch-shift anomalies.
- **Sub-surfaces & Borders:**
  - `surface-base`: `#09090F`
  - `surface-elevated`: `rgba(18, 18, 28, 0.7)`
  - `surface-overlay`: `rgba(28, 26, 46, 0.5)`
  - `border-tactical`: `rgba(0, 245, 255, 0.2)`
  - `border-subtle`: `rgba(157, 78, 221, 0.25)`
- **Typography & Readability:**
  - `text-primary`: `#EAEAF0` (95% brightness crisp gray-white for maximum legibility)
  - `text-muted`: `#8E8E9F` (low-attenuation technical metadata)
  - `text-dim`: `#4F4F63` (system timestamps and structural coordinates)

## Typography

The type ecosystem combines engineered geometry, high structural density, and uncompromising readability across heavy visual interfaces.

- **Headlines (`Space Grotesk`):** Delivers a technical, sharp modernist profile with assertive geometric curves. Headlines should utilize uppercase transformations for project categorization and editorial series names.
- **Body (`Noto Sans`):** Provides high-clarity neutral text delivery, universal character support (including Traditional Chinese fallback pairing via Noto Sans TC), and fatigue-free reading across project concept briefings, client manifests, and lore documentation.
- **Labels & HUD Data (`Space Mono`):** Dedicated to technical readouts, timeline metadata, artwork aspect ratios, software stack markers, and system interface prompts.
- **Typographic Rules:**
  - Technical labels (`label-sm`, `label-md`) must always render in uppercase with positive letter-spacing (`0.06em` to `0.1em`).
  - Numbers and versioning (e.g., `v2.04_SYS`, `24.09.2084`) strictly use `Space Mono` for monospace tabular alignment.

## Layout & Spacing

The layout model uses a disciplined 12-column responsive fluid grid structured around 8px baseline intervals, creating modular HUD viewports that dynamically adapt across hardware devices.

- **Desktop (>= 1280px):** 12-column grid, `margin-lg` (64px) lateral canvas offsets, `gutter-lg` (32px) separation. Content sections adopt asymmetrical layout rhythms—combining ultra-wide aspect hero canvas viewports with dense, segmented right-rail metadata panels.
- **Tablet (768px - 1279px):** 8-column grid, `margin` (32px) margins, `gutter` (24px) gutters. Complex artwork sidebars collapse into sticky bottom telemetry drawer overlays.
- **Mobile (< 768px):** 4-column grid, `margin-sm` (16px) margins, `gutter-sm` (16px) gutters. Full-bleed edge-to-edge illustration displays bordered by top and bottom contextual navigation ribbons.

Grid lines may be subtly exposed using 1px `border-tactical` guidelines with corner crosshairs (`+`) at primary intersections to reinforce the cybernetic viewport framework.

## Elevation & Depth

Visual hierarchy is established using high-tech planar layering, luminescence, and backdrop filtering rather than conventional drop shadows.

- **Base Canvas (Level 0):** Pure `#09090F` overlaid with a subtle 2px horizontal scanline repeating pattern (`rgba(0, 245, 255, 0.02)`) and optional 40px grid dot patterns.
- **Translucent Tier 1 (Level 1 - Display Surfaces & Grid Items):** `rgba(18, 18, 28, 0.65)` background with `16px` backdrop-blur. Outlined with a 1px border of `rgba(157, 78, 221, 0.3)`.
- **Translucent Tier 2 (Level 2 - Hovered Cards & Flying Panels):** `rgba(24, 22, 38, 0.85)` background with `24px` backdrop-blur. 1px active border gradient running from `#00F5FF` to `#9D4EDD`.
- **Overlay & Modals (Level 3 - Fullscreen Art Lightboxes, HUD Telemetry):** `rgba(9, 9, 15, 0.92)` with `32px` backdrop blur. Edged with dual corner bracket highlights.
- **Luminescence (Neon Glow):**
  - Interactive highlights use multi-stage neon emission: `box-shadow: 0 0 10px rgba(0, 245, 255, 0.4), inset 0 0 15px rgba(0, 245, 255, 0.15)`.
  - Alert/critical glows use pink radiance: `box-shadow: 0 0 14px rgba(255, 46, 147, 0.45), inset 0 0 8px rgba(255, 46, 147, 0.2)`.

## Shapes

The interface embraces a strictly sharp, angular visual geometry (`roundedness: 0`). Curved, organic forms are forbidden for system structures to reflect an industrial, cybernetic console environment.

- **Chamfered Cuts (45-degree angle clipping):** Primary cards, HUD ribbons, and command buttons leverage CSS clip-paths (`polygon(0 0, calc(100% - 12px) 0, 100% 12px, 100% 100%, 12px 100%, 0 calc(100% - 12px))`) to generate hard-cut cybernetic corners.
- **Corner Brackets:** Floating panels utilize pseudo-element L-shaped corner brackets (4px x 4px x 1px) positioned outside the main container perimeter.
- **Separators:** Segmented lines containing variable-length solid bars and periodic dotted intervals replace generic solid rules.

## Components

### Buttons & Interactive Controls
- **Primary CTA ("Engage / Transmit"):** Chamfered cut top-right corner. Background: solid `#00F5FF` with text `#09090F` (`label-lg`). Hover state triggers a subtle chromatic aberration glitch shift and neon bloom (`0 0 20px rgba(0, 245, 255, 0.6)`).
- **Secondary Action ("Terminal / Log"):** Ghost container with 1px `#9D4EDD` border and `rgba(157, 78, 221, 0.1)` background fill. Text: `#EAEAF0`. Hover shifts border to `#00F5FF` with matching text color.
- **Emergency / Urgent CTA ("Commission Artist"):** Chamfered cut bottom-left. High-voltage `#FF2E93` fill or heavy border with blinking state indicator square.

### Artwork Portfolio Cards
- Framed inside a Level 1 translucent pane. 1px subtle purple outline that transitions to cyan upon cursor proximity.
- The illustration within features a slight scanline mask that dissipates to 100% crystal clarity on hover.
- Micro-HUD telemetry bar pinned below each artwork: includes project title, resolution classification, creation timestamp, and genre badge (e.g., `[MECHA]`, `[ENVIRONMENT]`).

### Tags & Cybernetic Badges
- Inline monospace metadata chips (`label-sm`).
- Enclosed with sharp angular brackets: `<TAG_ID>` or bracket-bordered boxes with solid 2px colored status anchors on the left edge.
- Palette-coded: Cyan for technique/software, Purple for series/client, Pink for project status (`[OPEN FOR COMMISSIONS]`).

### Input Fields & Terminal Console
- Dark recessed background `rgba(9, 9, 15, 0.9)` with bottom-only or hard box 1px border in `rgba(0, 245, 255, 0.3)`.
- Typing prompt preceded by terminal symbol (`> `) in neon cyan.
- Active state flashes an input bracket and triggers a full neon cyan underline with ambient underglow.

### HUD Meters & Progress Bars
- Segmented block gauges (composed of 8–16 distinct geometric ticks) showing project completion, skill distribution, or commission load.
- Active segments illuminated in `#00F5FF` or `#FF2E93`, inactive segments set to `rgba(255, 255, 255, 0.08)`.

### Selection Controls (Checkboxes & Radios)
- Square-only, sharp-edged 14px boxes. Radio controls use diamond geometry (`rotate(45deg)`).
- Unchecked: 1px border `rgba(234, 234, 240, 0.3)` on dark surface.
- Checked: Centered neon cyan solid square with inner luminescence and sharp click feedback sound hook.
